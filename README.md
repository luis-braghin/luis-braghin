# Luis Braghin

**Desenvolvedor full-stack · Web e mobile · IA aplicada**

Desenvolvo plataformas completas para empresas reais, incluindo projetos contratados por clientes e produtos próprios em produção. Construo sistemas que conectam o atendimento ao cliente, os processos internos e a gestão do negócio, com aplicações web, painéis administrativos e aplicativos móveis.

Atuo do frontend ao backend, incluindo bancos de dados, autenticação, APIs, pagamentos, notificações e integrações com sistemas externos. Também integro IA aos fluxos em que ela resolve uma necessidade do produto.

## Stack de trabalho

| Camada | Tecnologias utilizadas nos projetos |
| --- | --- |
| Frontend | React, Next.js, TypeScript, Tailwind CSS |
| Backend e APIs | Node.js, Hono, Fastify, Edge Functions |
| Dados e acesso | PostgreSQL, Supabase, SQL Server, autenticação e RLS |
| Mobile | Capacitor, React Native e Expo |
| IA aplicada | APIs da Anthropic e OpenAI integradas a fluxos de negócio |
| Infraestrutura e qualidade | Cloudflare Pages/Workers, R2, Docker, Vitest e Playwright |
